## 🌐 3. Backend API Endpoints

- **`GET /api/v1/mirofish/status`**: Returns engine status, supported scenarios, and active swarm metrics.
- **`POST /api/v1/mirofish/simulate`**: Executes a real-time multi-agent swarm simulation:
  ```json
  {
    "scenario": "51_percent_floor_stress",
    "agents": 150,
    "rounds": 25
  }
  ```
- **`GET /api/v1/mirofish/report/latest`**: Returns the latest serialized prediction report (`server/data/mirofish_latest_report.json`).
